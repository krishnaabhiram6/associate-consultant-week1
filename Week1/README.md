# Associate Consultant Week 1

Learning Git Fundamentals

Topics Covered:
- Git Basics
- Commits
- Branches
- GitHub



Git Workflow Practiced

1. Created a Git repository using git init
2. Added files using git add .
3. Created commits using git commit
4. Connected repository to GitHub
5. Pushed changes using git push
6. Created a feature branch
7. Switched branches using git checkout
8. Created a Pull Request
9. Merged Pull Request into main
10. Pulled latest changes using git pull
